# Dashora

Premium static HTML admin dashboard template.

Open `index.html` in a browser or serve the folder with any static server.

## Included

- 33 HTML pages
- Bootstrap 5 layout with local vendor files
- Chart.js demo charts with local vendor files
- FullCalendar interactive calendar with local vendor files
- Light and dark mode
- Built-in LTR/RTL direction toggle
- Global layout modes: Default, Horizontal, Detached, Two Column, Hovered
- Documentation in `docs/index.html`

All third-party libraries are included in `assets/vendor/`; no runtime CDN dependency is required.
